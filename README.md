# 컴활 METRO

컴퓨터활용능력 2급 필기를 공부하는 웹 앱이에요. 지하철 노선도처럼 단원(역)을 따라가며 공부해요.

- **학습선**: 14개 역, 카드 186장 · 60초 용어 타임어택
- **응용선**: 단축키 트레이너(41개) · 미니 엑셀 수식 실습(14과제) · 서식 코드 실험실
- **시험선**: 40문항 40분 CBT 모의고사(문제은행 116문항), 과목별 시험, 쪽지 시험, 오답 다시 풀기

출제기준: 2024~2026 컴퓨터활용능력 2급 (Windows 10 · Excel 2021). 문제는 학습용으로 새로 만든 것이며 실제 기출 원문이 아니에요.

## 아이폰과 컴퓨터에서 기록 이어 쓰기

**가장 쉬운 방법:** Claude 앱이나 claude.ai에 게시된 컴활 METRO를 열면, 로그인한 Claude 계정에 기록이 자동 저장돼요. 토큰이 필요 없어요.

이 GitHub Pages 주소에서 쓸 때는 기록을 본인 GitHub 계정의 **비공개 Gist**에 저장해요.

1. 앱 오른쪽 위 **동기화** 버튼을 눌러요.
2. 안내에 있는 링크로 `gist` 권한만 있는 토큰(classic)을 만들어요.
3. 토큰을 붙여 넣고 **연결하고 동기화**를 눌러요.
4. 다른 기기에서도 같은 토큰을 넣으면 기록이 합쳐져요.

토큰은 각 기기의 브라우저에만 저장돼요. 연결을 끊어도 Gist의 기록은 남아 있어요.

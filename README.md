# 컴활 METRO

컴퓨터활용능력 2급 필기를 공부하는 웹 사이트예요. 첫 화면(노선도)에서 가고 싶은 곳을 골라 타요.

| 노선 | 파일 | 내용 |
|---|---|---|
| 2 학습선 | `metro.html` | 학습 카드 · 응용 연습(단축키, 수식, 표시 형식) · 시험선(강의 복습, 오답) |
| 3 CBT선 | (본인 전용) | 기출 CBT는 시나공 원문이라 이 공개 저장소에 올리지 않고 Claude 아티팩트와 USB 묶음에만 둠 |
| 5 위키선 | `wiki.html` | 1과목 22개 · 2과목 12개 위키 문서, 각주와 기출 함정 |
| 1 노트선 | `pdf/` | 합격 노트(컬러·흑백·2쪽 모아), 1과목 총정리, 날짜별 공부 노트 |

각 화면 왼쪽 위 **‹** 를 누르면 첫 화면으로 돌아와요. 예전 주소(`#study`, `#sync=…`)로 들어와도 METRO 앱으로 바로 넘어가요.

출제기준: 2024~2026 컴퓨터활용능력 2급 (Windows 10 · Excel 2021). METRO 앱의 문제는 학습용으로 새로 만든 것이며 실제 기출 원문이 아니에요.

## 아이폰과 컴퓨터에서 기록 이어 쓰기

**가장 쉬운 방법:** Claude 앱이나 claude.ai에 게시된 컴활 METRO를 열면, 로그인한 Claude 계정에 기록이 자동 저장돼요. 토큰이 필요 없어요.

이 GitHub Pages 주소에서 쓸 때는 기록을 본인 GitHub 계정의 **비공개 Gist**에 저장해요.

1. 앱 오른쪽 위 **동기화** 버튼을 눌러요.
2. 안내에 있는 링크로 `gist` 권한만 있는 토큰(classic)을 만들어요.
3. 토큰을 붙여 넣고 **연결하고 동기화**를 눌러요.
4. 연결된 기기에서 **자동 연결 링크 복사**를 눌러 링크를 카톡 '나에게 보내기'나 메모에 저장해 두세요. 다른 폰·PC에서는 그 링크만 누르면 바로 연결돼요.

토큰은 각 기기의 브라우저에만 저장돼요. 연결을 끊어도 Gist의 기록은 남아 있어요.

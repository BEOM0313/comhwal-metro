아이폰 · 컴퓨터 동기화

외운 카드, 틀린 문제, 시험 기록, 타임어택 최고 기록을 한 곳에 저장해서 기기를 바꿔도 이어서 공부해요.

지금 Claude에 로그인된 상태로 열어서, 따로 설정하지 않아도 Claude 계정에 자동 저장되고 있어요.

아이폰·컴퓨터·다른 PC 어디서든 Claude에 로그인한 채 이 앱 링크를 열면 같은 기록이 이어져요. 기록은 본인만 볼 수 있어요.

Claude 앱이나 claude.ai에서 컴활 METRO를 열면 설정 없이 자동 저장돼요. 이 주소에서 계속 쓰려면 아래처럼 GitHub 토큰을 한 번 연결하세요.

  1. GitHub 토큰 만들기 페이지를 열어요. (로그인 필요)
  2. gist 칸만 체크된 상태로 두고, Expiration은 시험이 끝날 때까지 쓸 수 있게 90 days나 No expiration을 골라요.
  3. 맨 아래 Generate token을 누르고, 나온 ghp_… 토큰을 복사해 아래에 붙여 넣어요.
  4. 다른 기기에서는 같은 토큰을 붙여 넣으면 같은 기록이 이어져요. 토큰은 메모 앱 같은 곳에 따로 보관해 두세요.

토큰은 이 기기 브라우저에만 저장되고, gist 권한만 있어서 저장소나 계정 설정은 건드릴 수 없어요.

카드를 외우거나 시험을 끝내면 몇 초 뒤 자동 저장돼요. 이 기기는 껐다 켜도 연결이 유지돼요.

다른 기기는 링크 한 번으로 연결 아래 링크를 내 카톡이나 메모에 저장해 두고, 다른 폰·PC에서 누르기만 하면 바로 연결돼요. 이 링크에는 기록 저장용 열쇠가 들어 있어요. 남에게 보내지 마세요.

연결을 끊어도 Gist의 기록은 지워지지 않아요.
